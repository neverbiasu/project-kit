# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, criticise the work and not the person, and no harassment of any kind.

## Reporting
Report unacceptable behaviour by opening a GitHub issue, or, if it should stay private, by contacting the maintainer through their GitHub profile. Reports are reviewed by the maintainer and kept confidential.

## Enforcement
The maintainer may remove comments, commits and issues that break this code, and may block repeat offenders from the repository.
